# АгроКорм — сайт комбикормового завода

Учебный MVC-проект на PHP для РГР по веб-технологиям. Тема: производство кормов / комбикормовый завод.

## Что внутри

- пользовательская часть сайта: главная, новости, о компании, история, сертификация, производство, партнеры, продукция, полезная информация, фото и видео, контакты, схема проезда, карта сайта;
- желто-оранжевая цветовая гамма, близкая к сайту комбикормового бренда Energy;
- форма заявки на продукцию с добавлением нескольких видов комбикорма в один заказ;
- автоматический расчет стоимости каждой позиции и общей суммы на клиенте и на сервере;
- сохранение заявок в БД и запись письма администратору в `storage/mail.log`;
- админ-панель с авторизацией;
- CRUD-разделы: новости, страницы, контакты, партнеры, категории продукции, продукция, рекомендации, фото, видео, категории полезной информации, статьи;
- в новостях можно менять текст, фото и ссылку на видео;
- в продукции можно менять категорию, описание, цену, фото и видео;
- раздел заявок в админке со сменой статуса и просмотром состава заказа;
- раздел «Менеджеры контента» для создания пользователей;
- мини-WYSIWYG редактор в админке;
- CSS/JS без CMS, структура разделена на MVC: `Controllers`, `Models`, `Views`.

## Быстрый запуск

Если терминал открыт в любой папке, запустить сайт можно одной командой:

```bash
cd /Users/dimass/WebstormProjects/feedmill-site && bash deploy_and_run.sh
```

Если вы уже находитесь в папке проекта:

```bash
bash deploy_and_run.sh
```

После изменений в коде пересобрать и перезапустить Docker-контейнер:

```bash
cd /Users/dimass/WebstormProjects/feedmill-site && docker compose up --build -d
```

Потом открыть сайт: <http://localhost:8080>

Админ-панель: <http://localhost:8080/admin>

Демо-доступ:

- `admin@example.com`
- `admin123`

Подробно все команды описаны в `COMMANDS.md`.

## Важное при обновлении старой версии

Если старая версия уже запускалась в Docker, БД может храниться в volume. Новая версия умеет делать миграции, но для полностью чистых демо-данных можно выполнить:

```bash
docker compose down -v
bash deploy_and_run.sh
```

## Структура проекта

```text
app/
  Controllers/       контроллеры сайта и админки
  Core/              база данных, авторизация, базовый контроллер
  Models/            модель-репозиторий для работы с БД
  Views/             шаблоны пользовательской части и админки
config/              настройки приложения
database/schema.sql  SQL-схема базы данных
public/              публичная папка Apache/PHP-сервера
scripts/init.php     создание БД, миграции и демо-данные
storage/             SQLite-БД и mail.log
```

## Примечания для сдачи

Проект не использует WordPress/Joomla/Drupal и другие CMS. Для локальной демонстрации используется SQLite, чтобы сайт разворачивался одной командой без отдельной настройки MySQL. При необходимости схему из `database/schema.sql` можно адаптировать под MySQL.
