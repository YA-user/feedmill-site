# Структура пояснительной записки

Этот файл можно использовать как заготовку для отчета по РГР.

## Аннотация

Разработан сайт комбикормового завода «АгроКорм» с пользовательской частью, административной панелью и формой приема заявок на продукцию, поддерживающей несколько видов кормов в одном заказе.

## Введение

Комбикормовый завод нуждается в сайте для публикации информации о предприятии, продукции, партнерах и полезных материалах, а также для упрощения приема заказов от клиентов.

## 1. Постановка задачи

Необходимо разработать сайт по теме «Производство кормов / комбикормовый завод» с разделами: главная, новости, о компании, партнеры, контакты, продукция, полезная информация, карта сайта, форма заявки. Также требуется административный раздел с авторизованным доступом, управлением контентом и правами менеджеров.

## 2. Анализ предметной области

Предприятие производит комбикорма для КРС, птицы, свиноводства, а также премиксы и БВМД. Клиентами являются фермерские хозяйства, птицефабрики, молочные комплексы и свиноводческие предприятия.

## 3. Проектирование базы данных

Основные сущности:

- users — пользователи админ-панели;
- pages — редактируемые страницы;
- news — новости;
- product_categories — категории продукции;
- products — продукция;
- recommendations — рекомендации по продукции;
- partners — партнеры;
- contacts — контакты;
- useful_categories — категории полезной информации;
- useful_articles — статьи;
- orders — заявки пользователей;
- order_items — позиции заявок;
- user_permissions — права контент-менеджеров на разделы админ-панели.

SQL-схема приведена в `database/schema.sql`.

## 4. Выбор инструментальных средств

- PHP 8 — серверная часть;
- SQLite — база данных для простой локальной демонстрации;
- Docker — запуск одной командой;
- HTML/CSS/JavaScript — пользовательский интерфейс;
- jQuery — JavaScript-библиотека для клиентской валидации и интерфейсных обработчиков;
- MVC — разделение логики на модели, представления и контроллеры.

## 5. Разработка раздела администратора

Админ-панель содержит авторизацию, CRUD-разделы, просмотр заказов и управление пользователями. Администратор может назначать контент-менеджеру доступ только к выбранным разделам. Для редактирования больших текстов используется встроенный WYSIWYG-редактор.

## 6. Разработка пользовательской части

Пользовательская часть содержит страницы с информацией о заводе, каталог продукции, слайдшоу на главной странице, полезные статьи, контакты с картой и форму заявки с расчетом стоимости по нескольким позициям. Сайт имеет многоуровневое левое меню.

Для обработки пользовательских и административных форм добавлен серверный парсер `App\Core\FormParser`. Он разбирает входные данные, нормализует email, телефон, числа и массивы, а также формирует список ошибок по правилам формы.

## 7. Тестирование

Проверить:

1. открытие главной страницы;
2. переходы по меню;
3. работу формы заявки;
4. появление заявки и состава заказа в админ-панели;
5. редактирование новости/страницы;
6. клиентскую валидацию обязательных полей;
7. работу серверного парсера форм на некорректных данных;
8. ограничение разделов для контент-менеджера;
9. запуск команды `php scripts/tests.php`.

## Заключение

В результате разработан учебный веб-сайт организации с MVC-структурой, базой данных, административной панелью и пользовательской формой заявки.
