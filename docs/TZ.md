# Техническое задание на разработку сайта комбикормового завода «АгроКорм»

## 1. Назначение сайта

Разрабатываемый сайт предназначен для публикации информации о комбикормовом заводе, продукции, партнерах и полезных материалах, а также для приема заявок на продукцию через веб-форму.

## 2. Пользовательская часть

Структура пользовательской части:

- Главная страница со слайдшоу видов продукции;
- Новости компании;
- О компании:
  - История компании;
  - Сертификация и научная поддержка;
  - Производство;
- Наши партнеры;
- Контакты и схема проезда на Яндекс.Картах;
- Продукция:
  - категории продукции;
  - карточки продукции;
  - рекомендации;
  - форма заказа;
- Полезная информация:
  - категории материалов;
  - статьи;
- Карта сайта.

## 3. Административная часть

Административная часть доступна только после авторизации. Разделы:

- Новости с возможностью редактирования текста, фото и видео-ссылки;
- Страницы;
- Контакты;
- Партнеры;
- Продукция:
  - категории продукции;
  - продукция с ценой, описанием, фото и видео;
  - рекомендации;
- Полезная информация:
  - категории информации;
  - полезные статьи;
- Заказы;
- Пользователи и права менеджеров контента.

Администратор имеет полный доступ ко всем разделам. Для контент-менеджера администратор выбирает доступные разделы: новости, страницы, контакты, партнеры, категории продукции, продукция, рекомендации, категории полезной информации, статьи и заявки.

## 4. Форма заявки

Форма заявки должна предоставлять пользователю возможность добавить несколько видов кормов в один заказ. Для каждой позиции указываются:

- вид продукции;
- количество.

Обязательные контактные поля:

- ФИО или наименование организации;
- контактный телефон.

Дополнительные поля:

- email;
- комментарий.

После отправки заявка и состав заказа сохраняются в базе данных. В локальной версии уведомление администратору дополнительно сохраняется в `storage/mail.log`.

Данные формы разбираются серверным парсером `App\Core\FormParser`: он нормализует строки, email, телефон, числовые значения и массивы позиций заказа, а затем возвращает список ошибок для вывода пользователю.

## 5. Расчет стоимости

Стоимость рассчитывается по формуле:

```text
Сумма позиции = цена продукции × количество
Итого = сумма всех позиций заявки
```

Расчет выполняется на стороне клиента для удобства пользователя и повторяется на сервере перед сохранением заявки.

## 6. Дизайн

- Корпоративные цвета по варианту: зеленый, голубой, белый.
- Оранжевый используется как вторичный акцент для отдельных элементов.
- Меню сайта: многоуровневое, слева.
- Ширина основного макета: от 1000 до 1200 px.

## 7. Технические требования

- Язык серверной части: PHP 8+.
- Архитектура: MVC.
- База данных: SQLite для локального запуска; схема вынесена в `database/schema.sql`.
- Клиентская часть: HTML, CSS, JavaScript.
- Подключена библиотека jQuery, используется для клиентской проверки форм и элементов интерфейса.
- Административные формы: серверная и клиентская валидация.
- Визуальное редактирование текста в админ-панели: встроенный мини-WYSIWYG редактор.
- Серверная обработка форм вынесена в отдельный парсер формы.
- CMS не используются.
